# Semana 5 Desarrollo Frontend
## Descripción de la actividad

En esta quinta semana realizarás una actividad sumativa de manera individual, llamada "Integrando nuestro frontend con backend", donde deberás entregar un desarrollo del frontend, teniendo en cuenta los requerimientos definidos en el caso. Además, se requerirá la implementación de un backend de tipo mock que deberá entregar información al frontend. La vía de comunicación se realizará utilizando REST y GraphQL.

## Instrucciones Específicas

1. Crea una aplicación para una agencia de viajes, utilizando HTML, JavaScript, CSS y React, donde los usuarios puedan explorar opciones de viaje, incluidos vuelos y hoteles. La aplicación debe:
    - Utilizar una API REST mock para listar los destinos disponibles, con información como el país y las actividades populares en el destino
    - Emplear una API GraphQL mock para consultar los vuelos y hoteles disponibles en cada destino, incluyendo detalles como precios, fechas y disponibilidad.
    - La interfaz debe permitir que los usuarios seleccionen un destino y, a continuación, puedan ver las opciones de vuelos y hoteles correspondientes para una experiencia completa de planificación de viaje.
2. Para la navegación del sitio deberás implementar y configurar React Router.
3. Para la entrega del proyecto, deberás disponibilizar en un repositorio de GitHub con el nombre viajes-nombre-apellido-siglaCurso y compartir la url del repositorio con tu docente.a
